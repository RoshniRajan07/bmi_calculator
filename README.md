BMI Calculator Web App:
A simple and interactive BMI Calculator built using React + Vite.
This app allows users to enter their details, calculate Body Mass Index, and view their health category along with a visual representation.

Features:
1)User name input
2)Height & weight with unit selection (cm/inches, kg/pounds)
3)Instant BMI calculation
4)Health category detection
5)Underweight
6)Normal weight
7)Overweight
8)Obese
9)Result image based on BMI category
10)Responsive and modern UI
